## 📚 About This Project

**Rohimaya Publishing** is an all-in-one AI-powered platform that helps authors write, format, design, narrate, and market their books — at 70% less cost than existing tools.

**Built by a published author, for authors.**

### 🎯 The Problem

Self-publishing authors struggle with:
- 💸 Expensive tools ($300+/year per tool)
- 🔀 Fragmented solutions (need 5+ different platforms)
- 🎨 Professional quality (can't afford designers/editors)
- 📈 Marketing (no budget for ads/promotion)
- ⏰ Time (wearing too many hats)

### ✨ Our Solution

**7 AI Tools in One Platform:**

1. 🖋️ **AI Writing Assistant** - Continue writing, expand scenes, polish dialogue
2. 📄 **Manuscript Formatter** - Format for KDP, IngramSpark, EPUB
3. 🎨 **AI Cover Designer** - Generate professional covers with DALL-E 3
4. 🎙️ **Audiobook Generator** - Convert manuscripts to audiobooks with AI narration
5. 🗺️ **Plot Outliner** - Structure stories with proven frameworks
6. 👥 **Character Creator** - Develop rich character profiles with AI
7. 📢 **Marketing Copy Generator** - Create blurbs, social posts, ads, press releases

**Pricing:** $9-$99/month (vs. $300+/year elsewhere)

## 🛠️ Tech Stack

**Frontend:**
- React / Next.js
- Streamlit (rapid prototyping)
- Tailwind CSS
- Shadcn/ui components

**Backend:**
- Python / FastAPI
- Cloudflare Workers
- Supabase (auth + database)
- Cloudflare R2 (storage)

**AI/ML:**
- Claude API (creative writing)
- OpenAI GPT-4 (DALL-E 3 for covers)
- ElevenLabs / Custom TTS (audiobooks)

**Automation:**
- n8n workflows
- Cloudflare Queues
- GitHub Actions

**Deployment:**
- Streamlit Cloud (prototypes)
- Cloudflare Pages (production)
- Vercel (alternative)
