# 🦚 Rohimaya Publishing - Streamlit Applications

This directory contains 7 professional-grade Streamlit apps for authors and publishers.

## Applications

1. **AI Writing Assistant** - Continue writing, expand scenes, polish dialogue
2. **Manuscript Formatter** - Format books for KDP, IngramSpark, EPUB
3. **AI Cover Designer** - Generate professional book covers with AI
4. **Audiobook Generator** - Convert manuscripts to audiobooks
5. **Plot Outliner** - Structure stories with proven frameworks
6. **Character Creator** - Build rich, consistent characters
7. **Marketing Copy Generator** - Create blurbs, ads, and social media posts

## Setup

Each app has its own directory with:
- `app.py` - Main Streamlit application
- `requirements.txt` - Python dependencies
- `README.md` - App-specific documentation
- `.streamlit/secrets.toml` - API key configuration

## Deployment

All apps are designed to deploy directly to Streamlit Cloud.

See `/docs/STREAMLIT_SETUP.md` for detailed deployment instructions.
