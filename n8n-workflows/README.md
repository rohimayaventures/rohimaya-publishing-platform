# 🦚 Rohimaya Publishing - n8n Automation Workflows

This directory contains automation workflows for the Rohimaya Publishing platform.

## Workflows

1. **user-onboarding.json** - Automated user registration, welcome emails, and setup
2. **book-publishing.json** - End-to-end book publishing automation
3. **content-publishing.json** - Blog and content distribution workflow
4. **payment-processing.json** - Payment handling and revenue tracking
5. **customer-support.json** - Support ticket routing and responses

## Setup

1. Install n8n locally or use n8n Cloud
2. Import JSON files into your n8n instance
3. Configure credentials for:
   - Email (SendGrid/Mailgun)
   - Database (PostgreSQL/Supabase)
   - Payment gateway (Stripe)
   - CRM (HubSpot/custom)

## Requirements

- n8n version 1.0+
- Webhook access
- API credentials for integrated services
